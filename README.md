## 職務要約

2020 年 10 月の大学在学中から業務委託（フリーランス）として 6 年間、Web アプリケーション開発に継続して参画。Next.js / TypeScript を中心としたフロントエンドを土台に、Laravel のバックエンド、Terraform による AWS / Google Cloud の IaC と CI/CD まで担当する。直近は、Claude Code などの AI エージェントが安全に開発を回すための仕組み（ガードレール、静的解析の独自ルール、CI の品質ゲート）の設計・導入を軸に、テスト実行の約 3 倍高速化やデプロイ時間の約 17% 短縮を実現した。36 か月参画した動画配信サービスでは、参画 3 か月でテックリードに昇進し、単価は契約当初の 1.7 倍になった。

- **AI エージェント向けのガードレール設計**
  AI が実際に起こした事故から逆算した禁止・確認ルール、フックの迂回検知、ガードレール設定そのものの編集防止（AI エージェントデモ基盤／アクティビティ予約システム）

  PHPStan の層間依存を検知する独自ルール、ESLint の 2 ルールの error 化による既存違反約 200 件の解消、ルール無効化時の理由の必須化（アクティビティ予約システム／AI エージェントデモ基盤／ファンクラブ）
- **CI/CD と開発基盤の高速化**
  テスト実行を約 3 倍高速化、デプロイ時間を約 17% 短縮、PHPStan のテスト解析を「60 秒でタイムアウト」から「11 秒で完了」に（AI エージェントデモ基盤／アクティビティ予約システム）
- **本番を守る構成とセキュリティ**
  環境ごとの設定の取り違えを防ぐ構成、認可の不備の修正、秘密情報を無停止で入れ替える仕組み（アクティビティ予約システム／AI エージェントデモ基盤／ファンクラブ）

#### 設計レビューの導入による品質の底上げ

実装者のコンポーネント設計スキルによって画面の品質がばらつき、保守性が下がっていた。実装に着手する前の設計レビューを提案し、レビュー観点の策定からチームの運用に乗せるまでを一人称で担当した。実装の手戻りとバグの発生が減り、各実装者の設計力も上がった。

#### リリース直前の品質担保

開発初期は 1 画面を 1 人が担当し、画面ごとの設計の質が担当者に依存していた。その負債がリリース直前に顕在化し、あるバグを直すと別のバグが出る状態だった。期限の範囲で根本の設計を見直しながらデバッグを進め、複数のバグをまとめて解消し、リリース時点で対応必須としていたバグを全件解消した。

#### 「1 作業者」で留まらない動き方

手が空いたときはチームで優先度の高いタスクを周囲と確認して取りに行き、プロダクトコード全体から PM・PL も把握していない技術的負債や生産性の改善点を見つけて issue 化した。バグを生みそうな UI はデザイナーと仕様を調整し、型安全な実装のために BFF のデータ型の変更を依頼するなど、ステークホルダーとの調整も担った。

#### チームの育成と橋渡し

コードレビューでのフィードバックと週次の勉強会で、メンバーの技術力を底上げした。日本語での言語化に苦労するメンバーもいたため、開発者から管理職への報告で情報の補足や状況の整理を行い、コミュニケーションエラーを減らした。

クライアントとの折衝をプロジェクトマネージャーと同席し、開発においては私 1 人で開発を進めていったので、環境構築からすべての画面実装、サービス公開に至るまでの過程をすべて 1 人で実施しました。  
運用フェーズにおけるコストの削減を見越して、動画コンテンツはクライアント様に専用の Youtube チャンネルを作成して頂いた上で  
そこにアップロードされた動画を Youtube API で取得する構成を取り、記事コンテンツに関しては WordPress 内に同様に記事のアップロードをしてもらう形として WordPress API で取得する構成を取りました。  
これにより運用フェーズにおけるコストの削減を見込みつつ、独自 CMS を開発することによる開発コスト増加を防ぐことができました。  
また、記事表示はなるべく早くしてほしいというクライアントからの要望に対して、SSG と ISR を用いて記事詳細画面の表示を早めることで対応しました。  
結果として納期の期限内にきちんと納品することができ、サイト自体の出来栄えも満足頂くことができたため  
その後の保守・運用も月額契約で発注して頂くこととなりました。
